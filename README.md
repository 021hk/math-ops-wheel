# 🎡 گردونه عملیات ریاضی

بازی گروهی کلاسی برای تمرین چهار عمل اصلی ریاضی — گردونه را بچرخانید تا به‌صورت شانسی مشخص شود تیمِ نوبت کدام عمل (جمع، تفریق، ضرب، تقسیم) را انجام دهد. **هیچ سوالی پرسیده نمی‌شود؛ تعیین عمل کاملاً شانسی است.**

## 🌐 نسخه آنلاین

این پروژه به‌صورت خودکار با GitHub Actions روی GitHub Pages منتشر می‌شود:

**https://021hk.github.io/math-ops-wheel/**

هر push به شاخه `main`، بیلد و انتشار جدید را به‌طور خودکار انجام می‌دهد (`.github/workflows/deploy.yml`).


## ✨ امکانات

- 🎯 گردونه چهار-سکتوری با انیمیشن نرم و چراغ‌های تزئینی
- 👥 ۲ تا ۸ تیم با نام دلخواه و رنگ اختصاصی هر تیم
- ⚙️ صفحه تنظیمات مجزا: تغییر نام و تعداد تیم‌ها
- 🏆 امتیازگیری دستی (+/−) برای هر تیم
- 📜 تاریخچه ۶۰ گردش آخر
- 💾 ذخیره خودکار همه‌چیز در حافظه مرورگر (با بستن اپ پاک نمی‌شود)
- 📲 قابل نصب به‌صورت اپلیکیشن (PWA) روی گوشی و کامپیوتر
- 🌐 کاملاً راست‌چین و فارسی با فونت وزیرمتن

## 🚀 اجرای محلی

پیش‌نیاز: [Node.js نسخه ۲۰ یا بالاتر](https://nodejs.org)

```bash
npm install
npm run dev
```

سپس در مرورگر باز کنید: `http://localhost:3000`

اگر از **bun** استفاده می‌کنید:

```bash
bun install
bun run dev
```

## 📲 نصب به‌عنوان اپلیکیشن (PWA)

بازی را با یکی از این مرورگرها باز کنید و از منو گزینه «افزودن به صفحه اصلی / Install» را بزنید:

- **اندروید (کروم):** منوی ⋮ ← Add to Home screen یا Install app
- **آیفون (سافاری):** دکمه اشتراک‌گذاری ⬆️ ← Add to Home Screen
- **کامپیوتر (کروم/اج):** آیکون نصب ⊕ در نوار آدرس

## 🤖 نسخه اندروید (APK)

بسته نصبی مستقیم اندروید در بخش [Releases](https://github.com/021hk/math-ops-wheel/releases) موجود است:

- `math-ops-wheel.apk` — نصب مستقیم روی گوشی (تمام‌صفحه، بدون نوار آدرس)
- `math-ops-wheel.aab` — باندل مناسب انتشار در گوگل‌پلی
- `signing.keystore` و `signing-key-info.txt` — کلید امضا؛ برای انتشار نسخه‌های بعدی لازم است، در جای امن نگه دارید

نصب APK: فایل را دانلود و باز کنید؛ اگر اندروید پرسید، اجازه «نصب از منابع ناشناس» را بدهید.
تأیید مالکیت اپ (assetlinks) در مخزن [021hk.github.io](https://github.com/021hk/021hk.github.io) میزبانی می‌شود.


## 🛠 اسکریپت‌ها

| دستور | کار |
|---|---|
| `npm run dev` | اجرای حالت توسعه روی پورت ۳۰۰۰ |
| `npm run build` | ساخت نسخه نهایی (خروجی استاتیک در پوشه `out/`) |
| `npm start` | اجرای نسخه نهایی |
| `npm run lint` | بررسی کیفیت کد |
| `npm run icons` | بازتولید آیکون‌های اپ (بعد از تغییر لوگو) |

## 📁 ساختار پروژه

```
src/
├── app/
│   ├── page.tsx               # صفحه اصلی: نمای بازی + نمای تنظیمات
│   ├── layout.tsx             # چیدمان راست‌چین، فونت وزیرمتن، متادیتای PWA
│   ├── manifest.ts            # مانیفست PWA
│   └── globals.css            # استایل‌ها و انیمیشن‌ها
├── components/
│   ├── game-wheel.tsx         # کامپوننت گردونه + کانفتی
│   └── ui/                    # کامپوننت‌های shadcn/ui (دکمه، کارت، ورودی، نشان)
└── lib/
    ├── game.ts                # ثابت‌ها، نوع‌ها و توابع کمکی بازی
    └── utils.ts               # ابزار استایل (cn)
public/                        # آیکون‌های PWA
scripts/make-icons.mjs         # اسکریپت تولید آیکون با sharp
```

## ☁️ انتشار آنلاین (رایگان)

ساده‌ترین راه، [Vercel](https://vercel.com) است:

1. پروژه را روی گیت‌هاب آپلود کنید (راهنمای پایین).
2. در Vercel با حساب گیت‌هاب وارد شوید و «Import Project» را بزنید.
3. بدون هیچ تنظیم اضافه، Deploy را بزنید — لینک دائمی می‌گیرید.

## ⬆️ آپلود به گیت‌هاب

**راه اول — از سایت (بدون نصب چیزی):**

1. وارد [github.com](https://github.com) شوید و روی **+ ← New repository** بزنید.
2. نامی مثل `math-ops-wheel` بگذارید و **Create repository** بزنید.
3. در صفحه جدید روی لینک **uploading an existing file** کلیک کنید.
4. همه فایل‌های داخل این پوشه (به‌جز `node_modules` و `.next` اگر موجودند) را بکشید و رها کنید.
5. **Commit changes** را بزنید — تمام!

**راه دوم — با خط فرمان:**

```bash
cd math-ops-wheel
git init
git add .
git commit -m "گردونه عملیات ریاضی"
git branch -M main
git remote add origin https://github.com/USERNAME/math-ops-wheel.git
git push -u origin main
```
